# kyrgyzstan-education-analytics
Интерактивный дашборд в Tableau Public для анализа динамики дисбаланса в нагрузке системы образования Кыргызстана (1990-2025 гг.)

**BI-инструмент**
Tableau Public, Power Query

**Источник данных**
Национальный статистический комитет Кыргызской Республики - stat.gov.kg
